# Arena de Cenários Reais

Expansão jogável do universo Zona Zero. A Arena transforma problemas reais em decisões com consequências sobre energia, orçamento, reputação, tempo e recursos.

## Cenários
- Apagão na cidade
- Golpe digital
- Crise financeira
- Enchente
- Equipe em conflito
- Falha no fornecedor

## Como testar
Abra `index.html` em um navegador moderno. Não exige backend.

Esta versão é um protótipo autônomo para validação de gameplay; a integração com o app React/Supabase pode ser feita depois sem perder o motor de decisões.
